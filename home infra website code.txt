====================================================
DATA ARCHITECTURE
====================================================

VERY IMPORTANT:

Do not store live inventory data permanently inside HTML.

HTML is only the presentation layer.

Final architecture should be:

HTML
↓
JavaScript
↓
API
↓
CRM Backend
↓
Database

Admin changes data in CRM.

Example:

Admin changes:

Plot A-101
Available → Booked

Database updates.

Public Plot Status page automatically displays:

A-101 = Booked

WITHOUT uploading the HTML page again.
